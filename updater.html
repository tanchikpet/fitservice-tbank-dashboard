1Подключение к GitHub
Загружает текущий data.json из репозитория. Без этого шага сохранение недоступно — чтобы случайно не затереть накопленные данные.
Токен GitHub
Нужны права на запись в репозиторий. Создать токен → Вводите только здесь, не пересылайте в чатах.
Репозиторий
Пароль дашборда
Этим паролем зашифрованы данные. Его вы сообщаете руководителям и менеджерам. Чтобы сменить пароль — введите новый перед сохранением.
Ключ обезличивания
Превращает телефоны клиентов в коды. Хранится только в этом браузере и никуда не отправляется. Сохраните его в надёжном месте: с другим ключом новые месяцы не свяжутся со старыми клиентами.
Не подключено
2Выгрузки из 1С
Перетащите один или сразу несколько файлов CSV или XLSX. Тип определяется автоматически по строке «Период»:
• за месяц (01.01.2026 – 31.01.2026) — итоги месяца, станции, клиенты и разбивка по дням;
• за день (01.09.2026 – 01.09.2026) — для текущего месяца, пока он не закрыт. Повторная загрузка того же дня заменяет его, а не дублирует.
📂
Перетащите файлы сюда или выберите на компьютере
Январь_2026.csv, 01_09_2026.csv, … · можно выделить сразу все · старый data.json тоже можно перетащить сюда для переноса

5Сохранить
Шифрует данные паролем и записывает data.enc.json в репозиторий. Имён и телефонов в нём нет. Дашборд подхватит данные через 1–2 минуты.
🔎 Найти клиента по телефону
В дашборде клиенты показаны кодами. Введите телефон — получите код, по которому клиента можно найти во вкладке «Клиенты». Работает только с вашим ключом.
